\section*{Scope and verdict}
This status report supersedes the dated technical audit for the items listed below. The primary 1,000-record Kaggle dataset is described by its uploader as synthetic. The project did not collect a survey. Its conclusions describe this file and its label structure; they cannot be generalized to a population. The production classifier is an educational internal label-recovery exercise, with no external validation.

\section*{Open limitations}
\begin{enumerate}
\item The source does not provide item wording, within-night timestamps, a sampling frame, or label-generation rules. A real bedtime prediction moment and target construct validity cannot be established from this file.
\item Earlier experiments may have inspected rows in the current 250-row holdout. The score is a historical internal benchmark, not a prospectively untouched evaluation.
\item NHANES and PhysioNet are separate context datasets, not external validation of the Kaggle classifier. NHANES masked-PSU Taylor variance accounts for strata and clusters, but adult complete-case domain handling and descriptive charts remain limited.
\item The optional multi-night PhysioNet dataset is still being downloaded locally. No result from that dataset is claimed until its raw files, checksums, and output tables are available.
\item Older figures and the historical three-class notebook remain as an audit trail. They should not be cited as results of the current binary classifier.
\item The saved joblib artifact requires its scikit-learn 1.5.2 training environment. The portable JSON bundle supports application inference; cross-version unpickling was observed to fail in a newer local virtual environment.
\end{enumerate}

\section*{Reproduction}
From the repository root, install the pinned training requirements and run the claim checks, simple baselines, and calibration scripts documented in \texttt{README.md}. The editable research report compiles with the documented report command, which checks its displayed values against saved tables. Streamlit tests and the compatible model-artifact check passed during this update. For current metric details use the production summary in \texttt{outputs/tables/}.
